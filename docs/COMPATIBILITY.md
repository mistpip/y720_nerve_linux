# 兼容性与验证范围 · 0.1

## 硬件范围

原生风扇控制、背光 CLI 和专用输入映射只针对 LENOVO 80Y4 / Y720-15IKB / BIOS 4GCN38WW。
其他 BIOS、同 ID 的第三方设备和其他联想型号不构成支持承诺。输入模块会保留未核验设备的普通 HID 解析。
风扇兼容目标是采用标准 hwmon 的软件，不是所有平台/软件。风扇一路联动，不提供独立双通道调速。

## 本版构建检查

| 内核 headers / 工具链 | 风扇模块 | 输入模块 | 可选 GameZone |
|---|---|---|---|
| 7.0.0-38-generic / GCC 15.2 | 编译通过 | 编译通过 | 未验证 |
| 7.2.11-cachyos-x64v3 / Clang 21.1.8 | 编译通过 | 编译通过 | 编译通过 |

以上仅为本地编译，不代表已在该内核/真实 Y720 上加载或验证功能。
缺少 vmlinux 时跳过 BTF 生成不等于编译失败；实际签名、加载、绑定和功能需要在目标环境验证。
可选 GameZone 源码源自先前审查的 7.1.6 接口，仍不自动替换系统模块。
其他内核未在此版检查；新内核可能需要按 WMI/HID/hwmon API 变化维护。

Fn+F7 更新另在真实 Y720 / BIOS 4GCN38WW / CachyOS 7.1.6-1-cachyos，
Clang 22.1.8、精确匹配 headers 上编译并临时加载输入模块（0.1）：

- `radio_zero_pulse=1`：两次物理 Fn+F7 各产生一组 KEY_RFKILL 按下/松开；
  用户确认飞行模式开启、关闭，四个 rfkill 条目同步 soft-block/unblock，硬阻塞均为 0。
- 随后单独 Fn 三次没有新增报告、按键事件或无线状态变化。
- 启用后的三次物理输入设备重新绑定，在每次 8 秒静置观察中没有合成飞行模式事件。
- UHID 虚拟设备（抓取虚拟输入，隔离真实系统策略）验证初始化过滤、重复报告去抖、
  非零标准路径及后续零报告隔离、错误描述符/版本拒绝专用映射；默认关闭时保留旧输入回归。
- 实际系统睡眠/唤醒仍未测；纯函数覆盖恢复后 5 秒过滤和跨恢复保留标准报告证据，不能代替实机验证。

只验证当前机器/固件；这不是通用零值 HID 映射。兼容项保持默认关闭，见 [FNF7.md](FNF7.md)。

## 离线回归

`make test` 包含风扇/输入纯函数、CLI 模拟 syscall、全部 PWM/RPM 和四区效果组合、
状态 JSON/只读字段、部分写/取消/竞争、严格 profile 解析、安装与版本一致性检查。
包括 ASan/UBSan 和 20000 个配置解析输入，不加载模块或写真实设备。
本版不包含内核故障注入参数、硬件采集脚本、机器日志、压力负载或开发历史。

## 尚需现场验证

状态接口/发布版本统一仍没有新实机测试；不得把 Fn+F7 的专项测试称为全功能实测。
其余 Fn 键与桌面动作、各动态灯效、睡眠/恢复和持续 GPU 重负载仍需现场验证。
摄像头物理断开时无法验证摄像头动作。背光无法可靠读回真实颜色/亮度/开关。
风扇曲线必须覆盖 CPU/GPU 及温度源失效，不能把离线测试曲线当成日常散热配置。
